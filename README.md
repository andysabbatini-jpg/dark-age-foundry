# Dark Age for Foundry VTT

Versione corretta del sistema Black Powder & Brimstone.

Questa versione include una correzione nella creazione degli oggetti dalla scheda del personaggio.

## Crediti e ringraziamenti

**Autore del sistema Foundry originale:** [Alexander "MrTheBino" Bierbrauer](https://github.com/MrTheBino).

Questo progetto deriva dal sistema originale [Black Powder & Brimstone per Foundry VTT](https://github.com/MrTheBino/bpnb-borg), realizzato da Alexander "MrTheBino" Bierbrauer. Il presente fork è mantenuto separatamente e include adattamenti e miglioramenti per Foundry VTT, tra cui aggiornamenti per la versione 14, modifiche alle schede dei personaggi e correzioni di compatibilità.

Il merito del lavoro originale e del sistema di base resta attribuito al suo autore. Questo fork non è il repository ufficiale del progetto originale.
